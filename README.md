# DIT014 Study

Russian learning companion: ten lectures, 43 small units and six mixed tasks.
Tutor-written explanations and exercises; this is not an official course website.

Open the published GitHub Pages address, choose a lecture and a block, write an attempt,
then reveal the answer or bring the attempt to the tutor in chat. Python is not executed
by this page. Drafts stay in the browser; export/import JSON to move them between devices.

The repository contains the self-contained study page and `.nojekyll` only, plus this README.
Original course slides remain in Canvas and require the appropriate access.

Publishing source: Settings → Pages → Deploy from a branch → main → / (root).
